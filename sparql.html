Querying

First, we used SPARQL queries to examine the icon and compare its description with other artworks. It took 2 SPARQL queries narrow the search.

Query 1. Searching for Russian icons in ArCo

I started by searching for icons associated with the Russian artistic tradition in ArCo. The query selects objects classified as icona whose Italian labels contain ambito russo. The results include icons with different subjects and dates. Among them, I found the eighteenth-century Icona agiografica – San Caralampo, identified by the ArCo URI ending in 0303280124. I selected this icon for further investigation.

PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX dc: <http://purl.org/dc/elements/1.1/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT DISTINCT ?object ?label
WHERE {
?object dc:type "icona" ;
a arco:HistoricOrArtisticProperty ;
rdfs:label ?label .
FILTER(LANG(?label) = "it")
FILTER(REGEX(STR(?label), "ambito russo", "i"))
}
ORDER BY ?label
LIMIT 100

Query 2. Identifying the icon of Saint Charalampius

PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX a-cd:
<https://w3id.org/arco/ontology/context-description/>
PREFIX dc: <http://purl.org/dc/elements/1.1/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT DISTINCT ?object ?label ?identifier ?description
WHERE {
?object dc:type "icona" ;
a arco:HistoricOrArtisticProperty ;
rdfs:label ?label ;
arco:uniqueIdentifier ?identifier .
FILTER(LANG(?label) = "it")
FILTER(REGEX(STR(?label), "ambito russo", "i"))
{
?object rdfs:label ?text .
FILTER(REGEX(STR(?text), "Caralampo", "i"))
}
UNION
{
?object a-cd:subject ?text .
FILTER(REGEX(STR(?text), "Caralampo", "i"))
}
OPTIONAL {
?object dc:description ?description .
}
}
ORDER BY ?label
LIMIT 20

Identification of Information Gaps

To identify possible information gaps in the ArCo record of Icona agiografica – San Caralampo (0303280124), I compared it with three other icons of the Russian artistic tradition: Sant'Alessandro Nevsky (1600211657), Abramo e i tre angeli (1800105581), and Annunciazione (0303280142). The comparison focused on the information available in core:description and a-cd:historicalInformation. I identified two gaps that could be addressed through knowledge graph enrichment.

Gap 1: Missing historical information. The record of Saint Alexander Nevsky contains a-cd:historicalInformation, which provides information about the saint's veneration, the iconography of the painting, and its technical characteristics. This property is not present among the direct properties of the Saint Charalampius record. Historical and iconographic information about Saint Charalampius could therefore be added if it can be supported by a reliable source.

Gap 2: Limited iconographic description. The core:description of the Saint Charalampius icon gives basic information about its material, rectangular shape, Russian artistic tradition, and religious subject. However, this information is not enough to understand what the icon depicts. In comparison, the description of Abramo e i tre angeli (0900596659) identifies the figures and gives details about the composition and frame.

We could enrich the description of Saint Charalampius by explaining how the saint is represented, including his clothing, gestures, and the objects he holds. We could also describe the arrangement of the surrounding life scenes and, where sources allow, identify the events they depict. This would give users a clearer understanding of the icon’s content and composition.

Query 3 — Identification of Information Gaps

The query compares three Russian icons and reveals two gaps in the record of Saint Charalampius (0303280124). First, it has no direct a-cd:historicalInformation value, unlike Saint Alexander Nevsky (1600211657). Second, its core:description gives only basic details, while Abraham and the Three Angels (1800105581) has a fuller description of the figures and composition.

The record could therefore be enriched with historical context and a more detailed iconographic description, based on further source research.

PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX core: <https://w3id.org/arco/ontology/core/>
PREFIX a-cd:
<https://w3id.org/arco/ontology/context-description/>
SELECT DISTINCT ?identifier ?description ?historicalInformation
WHERE {
VALUES ?object {
<https://w3id.org/arco/resource/HistoricOrArtisticProperty/0303280124>
<https://w3id.org/arco/resource/HistoricOrArtisticProperty/0303280142>
<https://w3id.org/arco/resource/HistoricOrArtisticProperty/1600211657>
<https://w3id.org/arco/resource/HistoricOrArtisticProperty/1800105581>
}
?object arco:uniqueIdentifier ?identifier .
OPTIONAL { ?object core:description ?description . }
OPTIONAL { ?object a-cd:historicalInformation ?historicalInformation
. }
}
ORDER BY ?identifier
